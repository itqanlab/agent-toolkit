# higgsfield-studio-video-explainer

Narrated explainer and story videos, built in 10-second blocks with one style and one narrator. The most expensive skill in the plugin: about 30 credits for every 10 seconds.

Part of the [Higgsfield Studio](../higgsfield-studio) plugin. It is installed with the plugin and spends credits only through the plugin's guard, which prices every job first, never pays twice for the same request and writes each cost to a ledger.

## Just ask

> *"make a 30-second explainer about how our app works"*

## Requirements

Everything the main skill needs: Node 18 or newer, Higgsfield's command line tool, and a signed-in Higgsfield account. See [higgsfield-studio](../higgsfield-studio/README.md#requirements).
