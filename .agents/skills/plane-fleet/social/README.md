# social

Posters, carousels and reels for social channels. Planned, not built yet.

Its roles are new fleet agents, built and tested the way the engineer and tester were, before
they run real work: copywriter, designer (posters, carousels), video editor (reels), brand
reviewer (blind, like the tester), publisher. The owner approves every post before it is
published. The design is in the fleet pipelines design doc; nothing in this section runs until
its roles and their tests exist.
