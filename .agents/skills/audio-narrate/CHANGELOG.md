## [1.0.0] - 2026-10-13

### Added

- Turn text into English or Arabic narration for free, with natural online voices, or offline with Piper.
- Make one file per line of a script, named for the scene order, to cut a video to.
- Fix words the voice says wrong with a pronunciation list, built in or kept in the project.
- Set up once with a check that says what is missing and how to install it. The engines and voices live outside the skill folder, and the offline voices download only when asked for.
- Clear messages when the free online voice service refuses, or when Piper's install path is too long, with what to do next.
